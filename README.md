# Business Decision Intelligence Engine

A portfolio-grade Data Science / Machine Learning project that analyzes e-commerce data to answer three business questions:

1. **What is happening?** — Descriptive analytics
2. **Why is it happening?** — Diagnostic analytics + ML models
3. **What should the business do next?** — Actionable recommendations

## Dataset

[Olist Brazilian E-Commerce Public Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — download and place CSVs in `data/raw/`.

## Project Components

- Customer Intelligence (segmentation, churn risk, CLV-style analysis)
- Product & Revenue Intelligence
- Customer Voice (review sentiment analysis)
- Decision Engine (combining model outputs into business recommendations)

## Stack

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Flask, PostgreSQL
